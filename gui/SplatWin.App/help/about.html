About SPLAT! for Windows

SPLAT! for Windows is a Windows front end for SPLAT!. It is free software under the GNU General Public License, version 2, the same license as SPLAT!. It comes with no warranty.

SPLAT!

SPLAT! (an RF Signal Propagation, Loss, And Terrain analysis tool), version 1.4.2, was started in 1997 by John A. Magliacane, KD2BD; SPLAT!'s documentation lists the others who contributed. It is free software under the GNU General Public License, version 2 or later. This app runs SPLAT! built for Windows from its published source, with only the small changes Windows needs (terrain file names, reading files in binary mode, the temporary folder), and its results are checked against SPLAT! on Linux. SPLAT!'s license is in the engine\COPYING file beside the app.

SPLAT!'s default propagation model, ITWOM 3.0, is by Sid Shumate, developed from the Longley-Rice Irregular Terrain Model of the US Institute for Telecommunication Sciences.
