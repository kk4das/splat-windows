Job folders

Every path analysis and coverage map runs in a folder of its own under Documents\SPLAT\Jobs, named by date, time and station, such as 2026-11-23 143005 K4HTA coverage. Nothing is overwritten; delete old folders when you no longer want them.

What's in one

  • The inputs the app wrote for SPLAT!: the stations' .qth files, the transmitter's .lrp, and its .az/.el pattern and the obstacles file if used.
  • Everything SPLAT! wrote: reports (…-to-….txt, …-site_report.txt), the map (.ppm), its .kml and colour files, graph data (.gp, in a folder per graph for paths).
  • splat-log.txt: SPLAT!'s exact commands and everything it printed.
  • run-again.cmd: runs exactly the same SPLAT! commands from the command line. Double-click it, or run it in a terminal, to repeat or check the job without the app.
  • For coverage maps, job.json, which the Earlier maps list reads.

Open the job folder (in the result) opens it in File Explorer; Settings opens the folder of all jobs.

SPLAT! names some files after the stations, in lower case (k4hta.qth), as SPLAT!'s own documentation does.
