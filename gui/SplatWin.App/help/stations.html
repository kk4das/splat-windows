Stations

A station is a named antenna position: a call sign, a repeater, a friend's house. The stations list is kept in Documents\SPLAT\stations.json. Paths and maps are always between or from stations in the list.

Adding a station

Click Add station…. The editor has four steps.

1. Find the place

Choose a tab, type, and click Find (or press Enter):

  • Call sign: looked up on QRZ.com if you're signed in (worldwide, needs a QRZ XML Logbook Data subscription), otherwise on callook.info (US licenses, free). Leave off /P, /M or a prefix. A call sign's position is where the license or the owner says, often a mailing address, not the antenna. The app says where the position came from and warns when it is only a zip code, state or country center.
  • Address: a street address, found by the US Census geocoder (US only) or OpenStreetMap. The app says how precise the match is (the building, only the street, only the town). A PO box is refused: it's the post office, not the antenna.
  • Grid: a Maidenhead grid square of 4 to 10 characters, such as FM18jw. The square is drawn on the map; the pin starts at its center.
  • Coordinates: decimal degrees as Google Maps shows them (38.9242, -77.2058) or degrees, minutes and seconds (38 55 27 N, 77 12 21 W).
  • Map: click the map where the antenna is.

2. Put the pin on the antenna

Drag the pin, or click the map, until it sits on the antenna itself. Zoom in: at VHF and UHF a few hundred meters can change the answer. Then tick The pin is on the antenna site. Moving the pin again clears the tick.

3. Name and antenna height

The name is usually the call sign; it names SPLAT!'s files, so plain letters, digits and punctuation only, and each name only once. The antenna height is above the ground at the pin, in feet or meters, not above sea level.

4. Antenna pattern (optional)

Without a pattern SPLAT! treats the antenna as sending equally in all directions. For a directional antenna, or to include a real antenna's pattern, click Choose .az file… and pick SPLAT!'s azimuth pattern file. A .el elevation pattern file with the same name beside it is read too. The pattern is kept with the station and used whenever that station transmits, in paths and in coverage maps (not line-of-sight maps, which don't use it).

  • A .az file: the first line is the pattern's rotation in degrees clockwise from true north; then one line per direction, "azimuth amplitude", azimuth 0 to 360, amplitude 0 to 1 (relative field strength).
  • A .el file: the first line is the mechanical tilt and the tilt's azimuth; then "elevation amplitude" lines, elevation -10 to 90 degrees.

The app checks the files against SPLAT!'s format before using them and says which line is wrong. Remove goes back to no pattern.

Click Save station. Back to stations (nothing saved), under the four buttons, leaves without saving.

Editing, deleting and exporting

  • Edit… (or double-click a station) opens the editor with its pin.
  • Delete asks first. The previous list is kept as stations.json.bak.
  • Export .qth… writes the station as a SPLAT! site file for the command line. SPLAT! wants longitude as degrees west, so the file has 77.2058 for 77.2058° W; the app does that for you.
  • A station's radio settings (frequency, ERP and the rest) are kept with it too; see Radio settings.

Importing .qth files

Import .qth… adds stations from SPLAT! site files (several at once). Files of the same name beside a .qth come too: a .lrp brings its radio settings, .az/.el its antenna pattern. A .qth height is in feet unless the file says meters; check the imported heights. If a station of that name already exists, the app asks whether to replace it.
